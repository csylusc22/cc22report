# 余晨琛个人作品集网站

这是一个无构建依赖的静态作品集网站，内容组织为 11 个全屏章节，覆盖个人简介、毕业设计、创作技术、AI 共创、论文阅读与未来规划。

## 如何完整保存

网站不是单独一个 HTML 文件，而是由页面、样式、交互脚本和素材共同组成。保存时请完整保留整个 `作品集补充网页化` 文件夹，尤其不要遗漏：

- `index.html`
- `styles.css`
- `app.js`
- `assets/` 文件夹

最稳妥的备份方式：关闭预览后，在文件资源管理器中右键整个 `作品集补充网页化` 文件夹，选择“压缩为 ZIP 文件”。以后把 ZIP 解压到任意位置，即可继续打开或修改。不要只复制 `index.html`，否则图片和视频会丢失。

## 本地预览

直接双击 `index.html` 即可浏览。为了确保视频在所有浏览器中正常加载，也可以在当前目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 文件结构

- `index.html`：页面内容与章节结构
- `styles.css`：视觉系统、响应式布局与动效
- `app.js`：菜单、章节侦测、滚动进度与鼠标视差
- `assets/`：经网页优化的作品素材
